# zuzu_bot
## ИНСТРУКЦИЯ ПО ЗАПУСКУ:

1. Установите зависимости:
bash
```
pip install -r requirements.txt
```

2. Замените ```'YOUR_BOT_TOKEN_HERE'``` в коде на токен вашего Telegram-бота.

3. Запустите бота:
bash
```
python main.py
```

4. Откройте **Telegram**, найдите своего бота и начните диалог командой ```/start```

5. Нажмите кнопку ```"Загрузить файл"``` и прикрепите Excel (.xls или .xlsx) с колонками:
   - title
   - url
   - xpath

6. Бот отобразит содержимое и сохранит его в локальную базу данных SQLite (```data.db```)
